# Framer Site Exporter

Инструмент для полного экспорта сайтов, созданных на платформе Framer. Скрипт копирует все ресурсы сайта включая HTML, CSS, JavaScript, изображения, видео, аудио, шрифты и документы.

## Возможности

- ✅ Полное копирование HTML страниц
- ✅ Загрузка всех CSS файлов
- ✅ Загрузка всех JavaScript файлов
- ✅ Копирование изображений (jpg, png, gif, webp, svg, ico, bmp, avif)
- ✅ Копирование видео файлов (mp4, webm, ogg, mov, avi)
- ✅ Копирование аудио файлов (mp3, wav, ogg, aac)
- ✅ Копирование шрифтов (woff, woff2, ttf, eot, otf)
- ✅ Копирование документов (pdf, doc, xlsx, pptx)
- ✅ Автоматическое обновление путей к ресурсам в HTML
- ✅ Поддержка srcset для адаптивных изображений
- ✅ Многопоточная загрузка для ускорения процесса
- ✅ Рекурсивный обход всех страниц сайта
- ✅ Статистика экспорта

## Требования

- Python 3.7+
- requests
- beautifulsoup4

## Установка зависимостей

```bash
pip install requests beautifulsoup4
```

## Использование

### Базовый пример

```bash
python framer_exporter.py https://example.framer.website -o ./export
```

### Параметры командной строки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `url` | URL сайта Framer для экспорта | (обязательный) |
| `-o, --output` | Директория для сохранения файлов | `./framer_export` |
| `-w, --workers` | Количество потоков загрузки | `10` |
| `-v, --verbose` | Включить подробное логирование | Выключено |

### Примеры использования

```bash
# Экспорт с настройкой количества потоков
python framer_exporter.py https://mysite.framer.app --output ./backup --workers 20

# Экспорт с подробным логированием
python framer_exporter.py https://site.framer.website -o ./export -v

# Быстрый экспорт с большим количеством потоков
python framer_exporter.py https://demo.framer.site -w 50
```

## Структура выходных файлов

После экспорта файлы организуются следующим образом:

```
export/
├── index.html              # Главная страница
├── about/
│   └── index.html          # Другие страницы
├── css/                    # CSS файлы
├── js/                     # JavaScript файлы
├── images/                 # Изображения
├── videos/                 # Видео файлы
├── audio/                  # Аудио файлы
├── fonts/                  # Шрифты
└── documents/              # Документы
```

## Как это работает

1. **Загрузка главной страницы**: Скрипт начинает с указанной URL
2. **Парсинг HTML**: Извлекаются все ссылки на ресурсы (CSS, JS, изображения, видео, и т.д.)
3. **Многопоточная загрузка**: Ресурсы загружаются параллельно
4. **Обновление путей**: Все пути в HTML обновляются на локальные
5. **Рекурсивный обход**: Найденные внутренние ссылки обрабатываются рекурсивно
6. **Сохранение**: Файлы сохраняются в структурированном виде

## Примечания

- Некоторые сайты Framer могут использовать динамическую подгрузку контента через JavaScript, который не будет выполнен при экспорте
- Внешние ресурсы (не с домена сайта) могут не копироваться
- Для сайтов с большим количеством страниц увеличьте параметр `--workers`
